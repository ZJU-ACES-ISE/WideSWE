Add `DotNetTraceCollectMode` (`default` | `collect` | `collect-linux`) and `DotNetTraceStopTimeoutSec`, with defaults that reproduce today's exact behavior. The CLI modes should remain under lifecycle control: send SIGINT, wait for the configured grace period, and keep partial traces if finalization times out. The failure should report the detected prerequisites and suggest `collect` for EventPipe collection. Make tracefs available at `/sys/kernel/tracing`. Ensure `dotnet-trace collect-linux` works when input or output is redirected: do not read interactive keys from redirected input or print interactive status updates to redirected output.
