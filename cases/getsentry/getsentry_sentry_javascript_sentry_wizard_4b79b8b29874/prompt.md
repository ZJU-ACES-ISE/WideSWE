Export and use `sentryOnError` for React Router error reporting.

Add a `sentryOnError` helper to the client bundle for leveraging React Router's `onError` hook on `HydratedRouter`.

The handler should report errors to Sentry and preserve React error context when React Router provides it. Errors reported through this hook should be treated as unhandled React Router `onError` errors.

Use the new handler in React Router setup generated by the wizard. For `@react-router/dev` version 7.11.0 or newer, generated client entry code and manual setup should install `onError={Sentry.sentryOnError}` on `HydratedRouter`; do not enable this path for older versions or when `@react-router/dev` is not installed.
