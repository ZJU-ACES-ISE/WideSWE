Add automatic wildcard detection and filtering for DNS results using a shared wildcard detector package.

Extract the shared wildcard detection core from `shuffledns` into `utils/dns/wildcard`. Preserve the original wildcard permutation, cache flow, reprobes, current-host revalidation, and transient-error behavior while making lookups injectable for reuse across tools. Expose `NewResolver`, `NewResolverWithDomains`, `LookupHost`, and `GetAllWildcardIPs`. Add `RegistrableRoot` so consumers can group wildcard detection per registrable domain; normalize case, trailing dots, and leading wildcard labels, support multi-level public suffixes, and reject IP addresses or non-registrable hosts.

Add `--auto-wildcard` mode that automatically detects and filters wildcard-backed results across multiple registrable domains in a single run. Keep the existing manual `-wd` flow unchanged, while making `--auto-wildcard` mutually exclusive with it; wildcard filtering should be rejected in stream mode, and auto detection should not depend on the manual wildcard threshold. Reuse the shared wildcard logic from `github.com/projectdiscovery/utils/dns/wildcard`, preserve normal `dnsx` output behavior for the selected query mode, use internal `A`/`AAAA` probes for wildcard decisions when needed, and normalize and validate manual `-wd` input such as `*.Example.COM.` without accepting malformed wildcard domains.
