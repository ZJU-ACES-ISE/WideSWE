Add a Stackdriver receiver through the Prometheus OpenTelemetry bridge.

The receiver should embed `prometheus-community/stackdriver_exporter` via the bridge. Decode YAML configuration directly into the exporter's `collectors.Config` using mapstructure with a `MatchName` function that maps snake_case YAML keys to PascalCase Go fields, without requiring mapstructure tags on the exporter side. Keep the exporter's `Config` free of receiver-specific concerns, pin the YAML key set so unintentional renames surface, build the runtime via `collectors.NewRuntime`, get all collectors via `runtime.Collectors()`, and register them on a `prometheus.Registry` for the bridge to scrape.

Make exporter validation opt-in via type assertion instead of forcing exporters with no OTel-specific validation logic to implement a no-op `Validate() error`. Exporters that need validation should still get it called; exporters that do not need validation can skip the method entirely. Method signatures that previously used `Config` should use `any`. Remove `ReceiverConfig.SetExporterConfig` and `ReceiverConfig.GetExporterConfig`, which only wrapped an in-package field.

Consolidate Stackdriver exporter config and introduce `collectors.NewRuntime` as the single assembly entry point. Keep `config/` as a pure value-type package with `Config`, defaults, `NewConfigWithDefaults`, `Validate`, and `Validated`; a successful validation should mark the config as validated, and `NewRuntime` should reject configs that have not been validated. Return a `Runtime` with `Collectors`, `CollectorsForPrefixes(prefixFilter []string)`, and `WithCache`; a nil or empty prefix filter should use all configured prefixes, while `WithCache` should reuse collectors per project and prefix filter until the configured cache lifetime expires. Return HTTP 500 for filter-path scrape errors instead of exiting the process.
